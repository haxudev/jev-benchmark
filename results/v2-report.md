- v2 与官方 Jev 选择一致：78/100；三模型选择相同：56/100，全部与参考一致。

## 复现与完整性

安装项目依赖后，在 `.env` 中配置已部署的 v2 服务（根地址不含 `/v1/systemone`）：

```dotenv
INTRANET_BASE_URL=http://127.0.0.1:8082
INTRANET_API_KEY=<服务密钥>
INTRANET_MODEL=Qwen3-1.7B-Jev
```

```bash
.venv/bin/python -m jev_benchmark --models intranet
.venv/bin/python -m unittest discover -s tests
```

第一条命令发起 100 次请求，成功后写入 `results/intranet.json`（再次运行会替换该文件）。
模型名仅为服务选择参数，复现前应确认部署权重为上述 v2 release。
在 [benchmark.ipynb](../benchmark.ipynb) 第 2 节重新运行查看结果单元格，
设置 `REPORT = "intranet.json"` 可展开本次逐题报告，排行榜自动纳入 v2。

## 结论

v2 在这套中文伴侣对话诊断题上取得 78%，优于已有 0.8B 基线；回避与保留表现较好，
借题表达和同末句上下文对照仍有明显缺口。模型原先训练于足球决策数据，本次为跨领域
评测；100 道合成、单一作者标注题的参考一致率不等同于真实伴侣意图理解能力或通用排名。
